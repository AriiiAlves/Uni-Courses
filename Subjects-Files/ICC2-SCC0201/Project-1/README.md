Na pasta `src/` está presente o código em C dos algoritmos escolhidos: Insertion Sort e Heap Sort. Também há um script `graphs.py` utilizado para gerar gráficos.

O arquivo em C possui um booleano `RUNCODES`. Para `RUNCODES = true` ele lerá os arquivos `.in` e `.out` e imprimirá o DEBUG na tela (comparação de v_in ordenado e v_out), além de calcular o tempo em ms para todos os casos aplicados a todos os algoritmos. Para `RUNCODES = false` ele apenas ordenará o vetor com o algoritmo designado pelo runcodes e emitirá uma saída simples.

Na pasta `charged-ieee`, está o relatório. Ele foi elaborado em typst, e na pasta está presente o pdf `report.pdf` (typst compilado). As tabelas de valores de tempo de execução utilizadas estão presentes em `charged-ieee/assets`.
